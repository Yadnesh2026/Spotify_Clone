# 🎵 Spotify Clone

A responsive Spotify-inspired music streaming interface built using HTML and CSS. This project recreates the core layout and modern UI design of Spotify, including a sidebar navigation menu, playlist sections, and a bottom-fixed music player.

The project focuses on frontend development fundamentals, responsive layouts, and modern UI recreation skills.
