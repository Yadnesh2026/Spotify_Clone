# Spotify Clone

A responsive Spotify-inspired web interface built using HTML and CSS. This project recreates the basic layout and design of Spotify, including a sidebar, playlist cards, and a music player section.

## 🚀 Features

* Responsive Spotify-inspired UI
* Sidebar navigation menu
* Music playlist cards
* Bottom-fixed music player
* Clean and modern design
* Simple and beginner-friendly project structure

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```bash
│── MainProject.html

```
